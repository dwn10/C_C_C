# Security Policy

## Supported Versions

The following versions of the modules and projects in this repository currently receive security updates:

| Project / Module | Supported Versions | Status |
| :--- | :--- | :--- |
| **Python Utilities** (`E-Rechnung`, `Leitweg-ID`, `XmlToPdf`) | Streamlit >= 1.54.0, requests >= 2.32.0, lxml >= 6.1.0 | :white_check_mark: |
| **Java Components** (`CRUD`, `Calculator`) | JDK 8+ / Current | :white_check_mark: |
| **Legacy & Archived Modules** | Previous versions | :x: |

---

## Reporting a Vulnerability

We take the security of this repository and its tools very seriously.

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report security vulnerabilities securely using GitHub's **Private Vulnerability Reporting**:

1. Navigate to the [Security tab](https://github.com/dwn10/C_C_C/security) of the `dwn10/C_C_C` repository.
2. Under "Reporting", click on **"Report a vulnerability"**.
3. Fill out the advisory form with detailed steps to reproduce the issue (PoC, affected components, and environment).
4. Our maintainers will review the submission promptly and coordinate a patch and responsible disclosure.

Thank you for helping keep our software secure!
